# قعدة فزعة 🚨
**يا منطلع سوا، يا منوقع سوا.** لعبة جماعية تعاونية من مشروع «صار بدها قعدة» — إعداد م. إياد حلوبي (@eyad.hloubi).

من 2 لـ12 لاعب، كل واحد من موبايله. 12 مهمة بيختارها الدولاب، و3 قلوب للقعدة كلها.

## المهمات
عدّوا سوا · الكيبورد المقسوم · الميزان · البرج · عبّوا الكاسة · الجسر · فكّ القنبلة · النبض · الطبلة · البازل المقسوم · تويستر الأصابع · الإطفائية

## أدوات الريس
- ⏭ **مرّر**: المهمة بتطلع من الدولاب بلا ما تاخد قلب.
- 🔁 **عيد**: بأي لحظة (قبل، خلال أو بعد المهمة، وحتى من شاشة النتيجة) — النتيجة القديمة بتنلغى، وإذا كانت فشل القلب بيرجع.
- 👥 **المشاركين**: تعديل، طرد، أو تسليم الريس بأي وقت (حتى بنص المهمة).
- 🏠 **البيت**: خلّصنا واعرضوا النتيجة، أو قعدة جديدة.

## التشغيل
```
npm install
npm start      # http://localhost:3000
```

## النشر على Render
1. ارفع المجلد على مستودع GitHub جديد.
2. على Render: **New → Blueprint** واختار المستودع (بيقرأ `render.yaml` لحاله).
3. مفتاح الإدارة `ADMIN_KEY` بيتولّد لحاله — بتلاقيه بإعدادات الخدمة ← Environment.

## صفحات
- `/` اللعبة
- `/admin` صفحة الإدارة (بدها ADMIN_KEY)
- `/stats?key=` إحصائيات JSON (بنفس مفتاح الإدارة)
- `/admin` كمان فيها تسكير أي قعدة شغّالة
